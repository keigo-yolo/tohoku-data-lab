# note.com 下書き自動生成

このフォルダには、note.com に投稿するための記事下書き（Markdown）を毎日自動生成して保存します。

## 背景・注意事項

note.com には記事投稿用の公式APIが公開されていません。そのため「完全自動投稿」ではなく、

1. 毎朝、下書き記事をこのフォルダに自動生成・コミット
2. 中身を確認し、内容を調整
3. note.com に手動でコピー＆ペーストして投稿

という運用にしています。非公式APIやログイン情報を使った自動投稿は、note.comの利用規約違反やアカウント凍結のリスクがあるため行いません。

## テーマローテーション

以下の4テーマを日替わりでローテーションします。

```
themes = ["お金", "節約", "防災", "時短"]
index = 年間通算日数（1/1を1日目とする） % 4
today_theme = themes[index]
```

例: 2026-09-04 は年間247日目 → 247 % 4 = 3 → `時短`

## ファイル命名規則

```
notes/drafts/YYYY-MM-DD-<テーマのローマ字slug>.md
```

slug対応表: お金=`okane` / 節約=`setsuyaku` / 防災=`bousai` / 時短=`jitan`

例: `notes/drafts/2026-09-04-jitan.md`

## 下書きのフォーマット

各下書きファイルは以下の構成にします。

```markdown
---
date: YYYY-MM-DD
theme: テーマ名
status: draft
---

# タイトル

（リード文）

## 見出し1
...

## 見出し2
...

## まとめ
...

**ハッシュタグ案:** #タグ1 #タグ2 #タグ3
```

## 自動生成の実行方法

このリポジトリを操作しているClaude Codeセッションに対して、毎日1回スケジュール実行（Routine）が送られ、以下を行います。

1. 今日の日付から上記ロジックでテーマを算出
2. 今日分のファイルが既に存在すれば何もしない
3. 存在しなければ、テーマに沿った1500〜2500字程度の記事下書きを作成し、上記フォーマットで保存
4. `claude/note-auto-posting-x8025l` ブランチにコミット・プッシュ

生成頻度やテーマ、保存先を変更したい場合はこのREADMEを更新してください。
